# sleep-debt-ledger

A single-file, hand-kept method for tracking sleep debt as a number that survives the week: you book the gap below your personal sleep-need baseline every night, never credit surplus, and read the balance weekly instead of averaging it away.

The page includes the ledger rule, a fully worked sample week, and what the running balance is for. No build, no dependencies, no data leaves the page. Open index.html in any browser.
